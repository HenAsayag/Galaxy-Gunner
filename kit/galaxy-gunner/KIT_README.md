# Galaxy Gunner — Video Match Conversion Kit

This package is designed to convert the existing WebGL/mobile shooter into the gameplay style visible in the user-provided reference video.

Start with:
`01_Master_Prompt/MASTER_PROMPT.md`

Then provide the AI coding agent with the full `03_Assets` folder.

The two large PNG boards are visual references for the new original art direction. Production sprites should be exported as transparent WebP/PNG atlases.
